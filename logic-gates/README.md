# Как компьютер думает с помощью 0 и 1

Образовательная анимация о семи логических элементах: **AND (И), OR (ИЛИ), NOT (НЕ), NAND (И-НЕ), NOR (ИЛИ-НЕ), XOR (исключающее ИЛИ), XNOR (равнозначность)**.

## Готовые файлы

| Файл | Что это |
|---|---|
| `logic_gates_reels.mp4` | Видео для Reels / Shorts: 1080×1920 (9:16), ≈64 с, 30 FPS, H.264 + AAC. Дикторская озвучка (женский голос), тихая электронная музыка, звуки переключателей, вшитые русские субтитры |

| `VERIFICATION.md` | Отчёт автоматической проверки |

## Сценарий видео

Тайм-коды подстроены под длительность реплик диктора (`src/voice-timing.js`, генерируется автоматически):

| Время | Сцена | Реплика |
|---|---|---|
| 0–7,6 с | «КАК КОМПЬЮТЕР ДУМАЕТ?» | «Как компьютер принимает решения…? Смотрите!» |
| 7,6–15,6 с | AND — И | «AND — логическое И. Результат — единица…» |
| 15,6–21,6 с | OR — ИЛИ | «OR — логическое ИЛИ. Достаточно хотя бы одной единицы.» |
| 21,6–28,8 с | NOT — НЕ | «NOT — логическое НЕ. Меняет ноль на единицу…» |
| 28,8–35,2 с | NAND — И-НЕ | «NAND — И-НЕ. Работает наоборот по сравнению с AND.» |
| 35,2–42,5 с | NOR — ИЛИ-НЕ | «NOR — ИЛИ-НЕ. Единица получается, только когда оба входа — нули.» |
| 42,5–49,6 с | XOR | «XOR — исключающее ИЛИ. Единица появляется, если сигналы разные.» |
| 49,6–56,2 с | XNOR | «XNOR — равнозначность. Единица появляется, когда сигналы одинаковые.» |
| 56,2–64,4 с | Все 7 элементов | «Вот так из нулей и единиц рождается цифровая логика!» → «0 И 1 — ОСНОВА ЦИФРОВОГО МИРА» / «ИНФОРМАТИКА С АННОЙ КОЛТУНОВОЙ» |

Реплика начинается вместе с появлением названия элемента (через 0,3 с после начала сцены), а схема перебирает комбинации, пока диктор объясняет правило.

Каждая схема: название → прорисовка символа → входы → импульс по проводам → смена цвета выхода → заполнение таблицы истинности.
Комбинации идут в порядке 00, 01, 10, 11 (для NOT: 0, 1). Выход и ячейка OUT в таблице меняются в один и тот же момент — когда импульс доходит до лампочки.

Цвета: зелёный = 1, красный = 0, жёлтый = названия, белый = подписи A, B, OUT, фиолетовый и тёмно-синий = корпуса.
Символы — ANSI/IEEE (как на референсе); рядом с названием показан значок по ГОСТ 2.743 (`&`, `1`, `=1`, кружок инверсии).

Важные элементы держатся в зоне y ≈ 100–1700 px, чтобы их не закрывал интерфейс Reels.

## Озвучка

**Какой голос использован.** Ключа ElevenLabs (и других облачных TTS) в среде сборки не было, а сам `api.elevenlabs.io` из неё недоступен. Поэтому озвучка сделана **локальным нейросетевым синтезом Piper (VITS), голос `ru_RU-irina-medium`** — женский русский голос, модель из релизов `k2-fsa/sherpa-onnx` на GitHub. Голос живой, но до студийного уровня ElevenLabs не дотягивает: интонация ровнее, чем у профессионального диктора.

Как улучшено качество:
- английские названия подаются в синтезатор русской транскрипцией («Энд», «Ор», «Нот», «Нэнд», «Нор», «Экс ор», «Экс нор») — варианты подобраны распознаванием речи; в субтитрах — оригинальный текст;
- служебные слова (И, ИЛИ, НЕ) подаются строчными: прописные синтезатор читает по буквам;
- паузы подсказываются только пунктуацией в тексте для синтеза (слова не меняются): «по сравнению с: энд!», «меняет ноль — на единицу»;
- каждое предложение синтезируется в 8 дублях, лучший выбирается автоматически: дубль распознаётся Whisper и сравнивается с текстом;
- между предложениями пауза 0,24 с, темп `length_scale=0.9` (умеренно быстрый);
- обработка голоса: срез низа, подъём «присутствия» 3 кГц, компрессия; музыка под голосом приглушается (ducking), итоговая громкость −14 LUFS.

**Как заменить голос на ElevenLabs** (когда будет ключ и доступ к API):

```bash
export ELEVENLABS_API_KEY=...            # ключ
export ELEVENLABS_VOICE_ID=...           # id женского русскоязычного голоса из Voice Library
python3 voice/make_voice.py --engine elevenlabs   # озвучка + новый тайминг
node render/render.js && node verify.js
```

Ветка ElevenLabs в `voice/make_voice.py` написана по документации API, но **в этой среде не проверялась** (не было ключа и доступа).

Текст озвучки и транскрипции для синтеза — `voice/script.json`.

## Интерактивная версия

Откройте `logic_gates_interactive.html` в браузере (на ПК или телефоне).

- кнопки AND … XNOR — выбор элемента (клавиши `1`–`7`);
- кнопки **A** / **B**, кружки входов на схеме или строка таблицы — переключение входов (клавиши `A`, `B`); у NOT только вход A;
- **▶ Автодемонстрация** — перебор всех комбинаций, **⏸ Стоп** — остановка, **↺ Повторить** — запуск сначала (`Пробел` — старт/стоп);
- **🔊 Звук** — щелчки и тоны выхода (высокий = 1, низкий = 0) через Web Audio.

## Как пересобрать

Нужны Node.js 18+, Playwright с Chromium, ffmpeg (libx264, aac), Python 3 + numpy, а для озвучки — `pip install piper-tts sherpa-onnx` и модели:

```bash
mkdir -p /opt/tts && cd /opt/tts
curl -LO https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-piper-ru_RU-irina-medium.tar.bz2
curl -LO https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-whisper-small.tar.bz2
tar xjf vits-piper-ru_RU-irina-medium.tar.bz2 && tar xjf sherpa-onnx-whisper-small.tar.bz2
```

```bash
cd logic-gates
node build.js              # собрать logic_gates_interactive.html из src/
python3 voice/make_voice.py  # озвучка (build/voice/*.wav) + src/voice-timing.js
node render/render.js      # обложка, звук (голос + музыка + эффекты), субтитры .srt и видео (≈5 мин)
node render/render.js --poster   # только обложка
node verify.js             # проверка → VERIFICATION.md
```

Если Playwright установлен глобально: `NODE_PATH=$(npm root -g) node render/render.js`.

Предпросмотр видео в браузере без рендера: откройте `render/video.html?preview` (есть пауза и перемотка).

## Как это устроено

- `src/logic-core.js` — общее ядро: логика вентилей, геометрия символов, провода, импульсы, лампочки, текст. Используется и видео, и интерактивной версией.
- `src/video.js` — детерминированный таймлайн: `renderFrame(ctx, t)` рисует любой кадр по времени.
- `render/render.js` — Chromium рисует 1680 кадров на canvas, PNG-кадры передаются в ffmpeg → H.264; затем добавляется звук.
- `render/make_sfx.py` — синтез звуков (щелчки, тоны, переходы) по событиям таймлайна, без внешних сэмплов.
- `render/make_audio.py` — сведение: голос + процедурная электронная музыка (112 BPM, Am–F–C–G) + эффекты, ducking.
- `voice/make_voice.py` — синтез озвучки с отбором дублей и расчёт таймлайна; `voice/check_voice.py` — проверка голоса в готовом MP4.
- `verify.js` — проверки:
  - таблицы истинности всех 7 элементов сверяются с эталоном, записанным вручную;
  - форма символа, кружок инверсии и число входов;
  - соответствие цветов значениям 0 и 1;
  - синхронизация: для каждого из 26 шагов проверяются состояние кадра и **цвет пикселей лампочки** до и после переключения;
  - текст не выходит за границы кадра (проверяется каждый 2-й кадр), минимальный размер надписей;
  - интерактивная версия на ширине 390 px и 1280 px: все элементы и комбинации, клики, демо, отсутствие ошибок JS;
  - параметры MP4 (ffprobe);
  - озвучка: каждая реплика внутри своей сцены; субтитры дословно совпадают со сценарием и показываются в кадре синхронно;
  - **голос в готовом MP4 распознаётся** Whisper по каждой реплике (сходство с текстом ≥ 0,75), голос громче музыки ≥ 12 дБ, вне реплик голосовая дорожка тихая.
